🚀 QUICK START
───────────────────────────────────────────────────────────────────────────

1. CONFIGURE CREDENTIALS
   cd backend
   Edit .env with:
   - MONDAY_API_TOKEN=your_monday_api_token
   - OPENAI_API_KEY=your_openai_api_key

2. START SERVICES (choose one)

   Option A - Docker (Recommended):
   ./start-dev.sh              (Linux/Mac)
   start-dev.bat              (Windows)

   Option B - Manual:
   Backend:  cd backend && uvicorn app.main:app --reload
   Frontend: cd frontend && npm install && npm run dev

3. ACCESS APPLICATION
   Frontend:  http://localhost or http://localhost:5173
   Backend:   http://localhost:8000
   API Docs:  http://localhost:8000/docs
   Health:    http://localhost:8000/api/health

4. TRY EXAMPLE QUERIES
   "How is our pipeline looking for energy sector?"
   "What's our revenue by sector?"
   "Show me delayed projects"
   "Generate leadership update"


🔧 CONFIGURATION
───────────────────────────────────────────────────────────────────────────

Required Environment Variables:
  MONDAY_API_TOKEN    - Your Monday.com GraphQL API token
  OPENAI_API_KEY      - Your OpenAI API key

Optional Environment Variables:
  CACHE_TTL          - Cache duration in seconds (default: 300)
  APP_NAME           - Application name (default: "Monday BI Agent")
  APP_VERSION        - Version string (default: "1.0.0")
